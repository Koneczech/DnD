    Úpravy na webu

    Úpravy se ukládají rovnou na GitHub (do repa kampaně). Na každém zařízení k tomu jednou zadáš osobní token GitHubu.

    1. Otevři Nový token na GitHubu (název, platnost a právo Contents jsou předvyplněné).
    2. Repository access: Only select repositories → DnD.
    3. Zkontroluj Permissions → Contents: Read and write, pak Generate token.
    4. Zkopíruj token (začíná github_pat_) a vlož ho sem.

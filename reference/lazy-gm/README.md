# Lazy GM's Resource Document

Podklad pro přípravu sezení (projekt Příběh, budoucí modul Příprava v Hubu). Anglický originál, stažený 1. 11. 2026 z `crit-tech/LGMRD` (verze z 21. 3. 2025).

| Soubor | Co v něm je |
| --- | --- |
| `LGMRD.md` | Lazy GM's Resource Document (Michael E. Shea, SlyFlourish.com) |
| `5e_Monster_Builder.md` | Lazy GM's 5e Monster Builder Resource Document (Teos Abadía, Scott Fitzgerald Gray, Michael E. Shea) |

## Co se nám hodí nejvíc

| Oddíl v `LGMRD.md` | K čemu |
| --- | --- |
| The Eight Steps of Lazy RPG Prep, The Lazy RPG Preparation Process | osm kroků přípravy; česká osnova je `sablony/priprava-lazy-dm.md` |
| Example Strong Starts | silný začátek sezení |
| Creating Secrets and Clues | tajemství a stopy |
| Connecting Characters | provázání postav s příběhem a mezi sebou |
| Spiral Campaign Development | rozvíjení kampaně od okolí postav ven |
| Quest Templates, Core Adventure Generators | rychlé zápletky |
| NPC Generator, Random Town Events, Treasure Generator | improvizace u stolu |
| Wilderness Travel and Exploration | cesta po Long Road |
| Lazy Combat Encounter Building, Monster Difficulty Dials, Monster Templates | souboje; podrobněji `5e_Monster_Builder.md` |
| Theater of the Mind Guidelines, Zone-Based Combat | souboje bez bitevní mapy (projektor na mapu nepoužíváme) |
